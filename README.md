# ASK-Vision

Desktop-система видеонаблюдения на `Python + PyQt5 + OpenCV + SQLite`. Захватывает видео с локальной камеры или по сети (RTSP/HTTP/MJPEG), детектирует движение и записывает ролики по событию или постоянно, ведёт журнал событий с экспортом в CSV.

Дипломный проект, разрабатывается одним автором.

## Возможности

- Live View нескольких камер одновременно, настраиваемая сетка
- Автообнаружение локальных камер (USB / `/dev/video*`)
- Детекция движения (OpenCV `BackgroundSubtractorMOG2`), порог и минимальная площадь настраиваются на камеру
- Два режима записи: по движению (с пре- и пост-буфером) и постоянная запись
- Расписание записи по дням недели и времени суток
- Лимит объёма архива с автоматическим удалением старых записей
- Встроенный плеер архива
- Журнал событий: экспорт в CSV, очистка журнала
- Пользователи, роли (admin/operator) и права доступа на 12 отдельных действий
- Темы и стили интерфейса, сворачивание в системный трей
- Автозапуск при старте системы и автологин (Windows и Linux)

## Статус проекта

Работающий прототип, не production-ready. Известные ограничения и открытые задачи — в [docs/AUDIT.md](docs/AUDIT.md) и в [Issues репозитория](https://github.com/yarivol/ASK-Vision/issues). Коротко, самое важное перед реальной эксплуатацией:

- При первом запуске создаются встроенные учётные записи `admin`/`password` и `operator`/`operator` — при первом входе приложение принудительно требует сменить пароль (минимум 8 символов), автологин до смены пароля не срабатывает.
- Пароли хранятся как солёный PBKDF2-SHA256 (200 000 итераций), старые хеши автоматически апгрейдятся при первом успешном входе.

## Стек технологий

- Python 3.12 (PyQt5 требует Python ≥ 3.8, верхняя граница не заявлена)
- PyQt5 — интерфейс
- OpenCV (`opencv-python-headless`) — захват видео и детекция движения
- SQLite — пользователи и журнал событий (файл `database.db`, создаётся автоматически)

Камеры (`cameras.json`) и настройки приложения (`app_settings.json`) хранятся в JSON-файлах рядом с исполняемым файлом, независимо от БД.

## Быстрый запуск

### Windows

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Либо запустить `Run.bat` при уже созданном `venv`.

### Linux

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 main.py
```

Либо `./run.sh` — сам создаст `venv` и установит зависимости при первом запуске.

При первом старте будет предложен вход: `admin` / `password` (см. раздел "Статус проекта" выше).

### Debian 12

Пошаговая инструкция для виртуальной машины, включая настройку графической сессии и проброс камеры: [DEPLOY_DEBIAN12.md](DEPLOY_DEBIAN12.md).

## Структура репозитория

```
ASK-Vision/
├── main.py             — точка входа
├── ui_main.py           — интерфейс PyQt5 и вся логика окон/диалогов
├── camera_thread.py     — поток захвата видео и записи на камеру
├── motion_detector.py   — детекция движения (MOG2)
├── database.py          — пользователи, роли, права, журнал событий (SQLite)
├── config.py             — чтение/запись cameras.json
├── settings.py            — настройки приложения, автозапуск (Windows/Linux)
├── utils.py                — хеширование паролей
├── requirements.txt
├── Run.bat / run.sh        — скрипты запуска (Windows / Linux)
├── DEPLOY_DEBIAN12.md      — инструкция по развёртыванию на Debian 12
└── docs/
    └── AUDIT.md            — технический аудит репозитория
```
